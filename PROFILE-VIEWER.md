# Inspecting a mobileconfig file

Open [`profile-viewer.html`](profile-viewer.html) in the published site to inspect an XML-format `.mobileconfig` file locally in your browser. The viewer lists basic profile metadata and payload types; it does not upload, install, or execute the profile. It does not support binary plist profiles or perform a security review. Always inspect the profile and trust its source before installing it through your device's normal settings.
