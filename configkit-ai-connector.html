ConfigKit AI Connector

Connect an AI assistant to your own ConfigKit account with scoped access and revocable credentials.

Checking your ConfigKit sign-in…

What the assistant can do

  • Read your ConfigKit account email and sign-in status (never your password or session tokens).
  • Read your own ConfigKit community profile.
  • Read up to 20 recent sent and received ConfigKit Mail messages; attachments, deleted and trashed messages are excluded.
  • List Drive metadata and find/read your XML files (up to 1 MiB per XML file).
  • Create XML files or update existing XML after your explicit approval. Updates create a separate backup file in your Drive first.

Every request is scoped to the account that created the token. Tokens expire after 30 days and can be revoked here.

ConfigKit app permissions

OAuth app owners can request separate ConfigKit permissions for profile, mail, Drive metadata, XML, App Store and Tool Studio access. Each connected account must approve the request, and database policies limit access to that account's own records. App owners can manage their own app listings and tools only when the matching permission is granted.

Using it with ChatGPT

ChatGPT custom MCP connections are plan-gated; ChatGPT Free cannot add a custom MCP server at this time. The OAuth permission framework and owner controls are now in place, but a ChatGPT-ready OAuth MCP connection still requires enabling Supabase OAuth 2.1 and the custom access-token hook, plus publishing an OAuth-protected MCP endpoint with protected-resource discovery. The personal token endpoint above is not itself that OAuth connection.

For safety, the connector never asks for your ConfigKit password, and it does not expose form submissions, mail attachments, or other users’ data. XML saving requires explicit approval for the exact change; updates require the latest file timestamp and create a backup first.
