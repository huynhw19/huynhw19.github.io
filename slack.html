One-time Slack app setup

  1. Create a Slack app for your workspace (or use an existing app).
  2. Under OAuth & Permissions, add the redirect URL shown below.
  3. Under Bot Token Scopes, add exactly chat:write and channels:read.
  4. Enable token rotation before installing the app so ConfigKit can refresh short-lived credentials securely.
  5. Copy the app's Client ID and Client Secret into Supabase Edge Function secrets, along with a new encryption key. Do not paste secrets into this page or commit them to GitHub.

Supabase project → Edge Functions → Secrets. Add: SLACK_CLIENT_ID, SLACK_CLIENT_SECRET, and SLACK_TOKEN_ENCRYPTION_KEY. Generate a unique encryption key of at least 32 characters (for example, openssl rand -base64 32).

Send a Slack message

Choose a public channel and send a message as the ConfigKit bot. The bot must be invited into the channel before it can post.

Permissions requested

chat:writechannels:read

  • Send messages as the ConfigKit bot.
  • List public channels so you can select a destination.
  • No access to read message history, private channels, direct messages, files or member lists.

For posting, invite the ConfigKit bot to the target channel using Slack’s channel member controls. ConfigKit does not request permission to join channels automatically.
