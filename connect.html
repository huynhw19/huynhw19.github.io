ConfigKit Connect

Link a financial institution through Basiq’s hosted consent experience, then review connected accounts, balances and recent transactions in one place.

Sandbox integration. This build is configured for Basiq sandbox only. It is not a bank account, does not move money, and does not initiate payments. Sandbox institutions and records are test data. Live Open Banking requires Basiq approval and separate production configuration.

First-time setup

The page and secure backend are deployed. To activate a sandbox connection, the ConfigKit owner must:

  1. Create/configure a Basiq application and its consent policy and choose the sandbox institutions to offer.
  2. Set the Basiq Consent UI redirect URL to https://huynhw19.github.io/connect.html.
  3. Add the Basiq API key as the BASIQ_API_KEY secret in Supabase → Edge Functions → Secrets. Never put this key in GitHub or browser code.

How the connection works

  1. You choose a financial institution on Basiq’s secure hosted consent page.
  2. You review and approve the requested data sharing with Basiq.
  3. ConfigKit requests account and transaction data through its secured backend.
  4. You can refresh or disconnect an institution from this page.

ConfigKit does not ask for, collect or store your bank login password. Do not send bank credentials to ConfigKit support.

Financial data is sensitive. Only connect accounts you are authorised to access. ConfigKit Connect currently uses Basiq sandbox; live data is not enabled by this page. Privacy · Help Centre
