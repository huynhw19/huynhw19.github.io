Prepare a mobileconfig profile

Paste XML profile text or choose an XML .mobileconfig file. We check that it is an XML property list, then let you download it for review. Processing happens in your browser; nothing is uploaded.

This page cannot install profiles. Profiles may make significant changes to a device, including adding certificates, network settings, or management controls. Only install a profile from a source you trust, inspect all its contents, and approve installation yourself in your device’s settings. This basic check is not a security review.

Install it yourself after reviewing

Downloading does not install or activate a profile. Follow the prompts on your device, and stop if the displayed organization or requested settings are unexpected.

  • iPhone or iPad: download the profile to the device, open the downloaded profile (or the “Profile Downloaded” notice in Settings), then review it in Settings and choose Install only if you trust it. The exact menus vary by iOS/iPadOS version.
  • Mac: download the file, open it, then review the profile in System Settings (often under Privacy & Security or Device Management) and approve installation only if you trust it. Menus vary by macOS version.

Some profiles require administrator approval, may be restricted by your organization, or may not be installable on your device. Check current Apple instructions for your OS version.
