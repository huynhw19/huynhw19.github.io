Mobileconfig connection speed test

Check the internet connection your device is using while a profile is installed. For a useful comparison, run the test once before installing a profile and again afterward, using the same device and network.

What this measures: your device’s current connection, not the mobileconfig file itself. A profile is settings data; it does not have a speed. DNS, VPN, proxy, or filtering settings in a profile may affect connectivity, but results vary with signal, server load, and other conditions.

Run a connection test

The test measures latency, download speed, and upload speed against Cloudflare’s public speed-test service. It sends test data only—not your profile or its settings.

Privacy: starting the test contacts speed.cloudflare.com. Cloudflare may receive your IP address and standard request metadata. The test runs only after you press the button; no results are saved by this page.

This is an approximate browser test, not a guarantee of performance or profile compatibility. For better comparisons, pause other downloads and repeat the test several times.
