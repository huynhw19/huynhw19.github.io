ConfigKit AI Docs

A friendly guide from your first question to using web research, weather, saved chats and connected ConfigKit context.

Beginner friendly

1. What is ConfigKit AI?

ConfigKit AI is an assistant inside ConfigKit. Ask it to explain features, help plan tasks, troubleshoot workflows, learn technology topics or understand how to use ConfigKit tools. It can guide you, but it does not directly operate your account or change your settings.

Start with a clear question

Instead of “Help”, try “Show me how to create my first task in Planner, step by step.” You can ask follow-up questions to get more detail.

2. How to get better answers

Give context
Say what you're trying to achieve and which ConfigKit page you're using.
Set your level
Ask for a beginner explanation, or request advanced technical detail.
Ask for a format
Request numbered steps, a checklist, examples or a short summary.
Refine the answer
Say “make step 2 simpler” or “give me an example”.

Example prompts

  • “Explain this like I'm completely new to it.”
  • “Give me a safe step-by-step checklist.”
  • “Compare these options in a table.”
  • “What should I check if this feature isn't working?”

3. Web search

Turn on Search the web before sending a question when you need current information. ConfigKit AI uses Tavily to retrieve a small set of web results and can include links in its answer.

  • Useful for recent news, current product details, documentation and changing facts.
  • Search is optional. Leave it off for ordinary questions to avoid using search credits.
  • Open the linked sources and verify important claims. Search snippets can be incomplete or out of date.
  • Web pages are untrusted content. Ignore any page text that asks you to reveal secrets or change account settings.

4. Weather and live conditions

Ask for weather in a named city, such as “What's the forecast in Melbourne tomorrow?” ConfigKit AI uses Open-Meteo for current conditions and a short forecast.

For “weather at my current location”, your browser asks permission to share your location. You can deny permission and ask about a city instead. Your coordinates are used for the weather lookup, not added to your saved ConfigKit profile.

5. Automatically save conversations to your account

  1. Sign in to ConfigKit AI.
  2. Ask a question and receive a successful answer. ConfigKit AI automatically saves the conversation to your account after each successful reply.
  3. Open My saved conversations to reopen a chat later. Use Refresh saved list if needed.
  4. Choose Delete beside a saved chat to remove it from your account.
  5. Save now is available as a manual retry if an automatic save fails.

ConfigKit AI keeps up to the most recent 80 messages in each saved conversation. It sends only the most recent 8 messages as conversation context with each AI request. Saved conversations are private to your signed-in account through Supabase Row Level Security. Only save information you are comfortable retaining in your account. Do not save passwords, API keys, recovery codes or other secrets.

6. AI Control Centre

Use AI Control Centre to customise response style, answer length, expertise level, default web research behaviour, memory personalisation and custom instructions. Preferences are saved to the signed-in user's account and applied to future AI responses. Web research can still be changed for an individual question using the search checkbox. Custom instructions are treated as user preferences and do not override safety or accuracy requirements.

7. AI Memory Centre

AI memory is separate from saved conversations. Choose your preference in the Memory Centre on the ConfigKit AI page:

  • Save automatically: ConfigKit AI saves useful details when you explicitly share preferences, projects or goals in supported phrasing.
  • Ask before saving: ConfigKit AI suggests a memory and waits for you to approve it.
  • Memory off: no memories are added or sent to the AI. Existing memories remain in your account until you delete them.

You can add memories yourself, review them, edit them or delete them at any time. Memories are private to your signed-in account using Supabase Row Level Security. When memory is enabled, saved memories are included in the question sent to Groq to personalise the response. When memory is off, they are not sent. Avoid storing sensitive information such as passwords, recovery codes, private keys or financial account details.

8. Optional ConfigKit context

The Planner and Education context checkbox lets ConfigKit AI include a limited read-only snapshot of relevant Planner items and published Education assignment details for that question. It is optional and only applies when checked. It does not include finance transactions, passwords or authentication secrets.

9. Privacy and safety

  • Your AI chat is sent to the configured AI provider to generate an answer.
  • If web search is enabled, your query and retrieved snippets are used to prepare the answer.
  • Don't paste passwords, API keys, passkeys, recovery codes or private financial details.
  • AI can make mistakes. Verify important medical, legal, financial, security and technical decisions with authoritative sources.
  • ConfigKit AI offers guidance; it does not itself make changes to your account or other ConfigKit tools.

10. Troubleshooting

Web search does not work

Check that the web-search checkbox is enabled. If a usage-limit or configuration message appears, turn search off for that question and try again later.

Saved conversations won't load

Confirm you're signed in to the same ConfigKit account, then use Refresh saved list. Your saved chats are account-specific.

Weather can't find a place

Try a larger nearby city or check the spelling. For current-location weather, allow location access in your browser.

The AI gives an unclear answer

Ask it to explain one part at a time, provide an example, or show its steps. For current facts, enable web search and check the sources.
