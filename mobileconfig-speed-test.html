⌘ ConfigKit · Connection tool

Mobileconfig speed test

Measure the internet connection your device is using with a mobileconfig profile installed, then compare it with a test run before installation. The profile itself does not have a speed; this checks your device’s current connection.

Start mobileconfig speed test →

Privacy: The test contacts Cloudflare’s public speed-test service and may share your IP address and standard request metadata. It sends test data only—not your profile or its settings.

For a useful comparison, use the same device and network, pause other downloads, and repeat the test several times.
