Sharing & access

Choose what leaves your private Drive. Public publishing creates a separate public copy; unlisted publishing uses a non-advertised link. Turning a project private removes that public copy.

The existing Drive security boundary is preserved: project files and version snapshots stay private to their owner. Public previews use a separate public bucket and never change the existing private Drive bucket or its RLS policies.

Access model

PrivateOnly you can access the project file and metadata.
Default
PublicAnyone can discover and play the published copy.
Showcase
UnlistedAnyone with the link can play; it is not listed in the showcase.
Link only

Collaborator invitations and shared editing are reserved for a follow-up secure access service. We won't pretend that a metadata-only permission grants access to private Drive bytes.
