Project

ConfigKit is an independent, browser-based demonstration project maintained in the huynhw19/huynhw19.github.io repository. The site’s HTML, CSS, JavaScript, and profile-builder examples are part of this project.

No third-party images, icon packs, or JavaScript libraries are required by the profile builders.
