DNS profile builder

Create a basic Apple DNS Settings configuration profile for a DNS-over-HTTPS (DoH) or DNS-over-TLS (DoT) resolver. The profile is generated in your browser and is not uploaded.

Review before installing. A DNS profile can route your device's DNS queries through the resolver you specify. The resolver may learn which domains your device looks up. Use only a resolver you trust, verify its endpoint with its operator, and inspect the generated profile before installing. This tool does not install profiles.

Install manually after review

      
Open the downloaded file on your device and follow its profile-installation prompts. Review the organization and requested DNS settings before approving. You can cancel if anything is unexpected. Installation steps and support vary by OS version and organization management; consult current Apple instructions. Removing the profile may restore the previous DNS behavior.
