Proposed experience

Familiar sign-in. Clear user control.

The proposed first release is deliberately narrow: use ChatGPT as an identity provider for ConfigKit account creation and sign-in. Users would still control whether they link an existing ConfigKit account.

Return securely

ConfigKit completes the supported OpenID Connect flow and validates the returned identity.

The person creates a ConfigKit account or explicitly links an existing account.

Privacy & security

Start with the minimum necessary access.

🪪

Identity only

Initial requested capability: sign-in only. No request for ChatGPT plan usage, conversation history, memory, files or unrelated account data.

🛡️

Standards-based flow

Prepared to implement OpenID Connect Authorization Code with PKCE, exact redirect URIs, state validation, secure token handling and issuer/client/subject account binding, subject to OpenAI's approved integration specification.

🤝

Separate consent

Signing in would not silently grant access to ConfigKit resources or other integrations. Those permissions remain separate and user-controlled.

Why this is useful

A smoother first step into ConfigKit.

People already use ChatGPT across their work and creative projects. A familiar sign-in option could reduce account friction, make onboarding easier, and let people try ConfigKit without creating another password. ConfigKit would remain responsible for its own accounts, authorization, privacy disclosures and support.

Application-ready summary

What we plan to tell OpenAI

Requested capability: Sign in only

ConfigKit is an independent web-based toolkit that helps people build and inspect device configuration profiles and use practical digital workflow tools in one place. We would like to integrate Sign in with ChatGPT as an additional account sign-in option on https://huynhw19.github.io/.

The intended experience is identity-only account creation and sign-in. Users would be able to create a ConfigKit account or explicitly link an existing account using their ChatGPT identity. We are not requesting ChatGPT plan usage in the initial integration.

ConfigKit has already built and tested its own OAuth 2.1 / OpenID Connect identity-provider infrastructure for third-party applications, including a consent experience and permission-scoped access controls for supported resources. For this integration, we would implement OpenAI's approved OpenID Connect Authorization Code with PKCE flow, validate the identity response, and keep ChatGPT sign-in separate from all other ConfigKit permissions.

The benefit is a simpler onboarding experience for people who already use ChatGPT, while keeping account linking, data access and user consent explicit. We would welcome guidance on eligibility, technical review, branding requirements and the next steps for the Sign in with ChatGPT programme.
Next step

Request review through OpenAI's official channel.

OpenAI currently describes website Sign in with ChatGPT as a limited programme for selected commercial partners. Submitting interest is not approval and does not guarantee a client ID or a timeline.

Important distinction
This page is a proposal prepared by ConfigKit, not an OpenAI application submission, endorsement or approval. We will only add the ChatGPT sign-in button after OpenAI approves the integration and issues the required client credentials.
