Web clip builder

Create a simple configuration profile that adds a website shortcut to the Home Screen on supported Apple devices. The profile is generated in your browser and is not uploaded.

Review before installing. A web clip opens the URL you specify. Use a site you trust and check the URL carefully. The generated profile is unsigned and this tool does not install it.

Shortcut settings

Shown in device profile settings.

HTTPS is recommended. HTTP is allowed for sites that specifically require it.
