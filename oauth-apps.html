OAuth apps

Register an application that may request permission to connect with ConfigKit accounts. Approved registrations receive a provider Client ID. Public clients use PKCE; confidential server-side clients also receive a Client Secret stored in Supabase Vault.

One-time setup required: In your Supabase project, open Authentication → OAuth Server, enable OAuth 2.1 Server, and set Authorization Path to /oauth-consent.html. Set the Auth Site URL to https://huynhw19.github.io. The OAuth consent page and client provisioning are ready, but the server setting must be enabled in the Supabase dashboard before OAuth sign-in can work.

Provider endpoints: https://gwhqnqzzlgslwgijkkpt.supabase.co/auth/v1/oauth/authorize · /auth/v1/oauth/token · /auth/v1/.well-known/jwks.json
