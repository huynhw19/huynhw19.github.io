Getting started

  1. Use ConfigKit to build a profile. Review the settings and generated profile before installing it on any device.
  2. Add each student below with their name and email address. Use an email they can access; they must register with this same email.
  3. Share the student sign-in page. Students sign up, confirm their email, then sign in to view their student dashboard.
  4. Create an assignment below, select a student, add instructions and an optional due date, then publish it when it is ready. Published assignments appear in that student’s dashboard.
  5. To enable student record linking, first complete the student login database setup in your Supabase project.

The site QR code opens ConfigKit for students. Education status is self-declared, and teachers should never ask for or set a student's password. Test with sample data before using real student information.
