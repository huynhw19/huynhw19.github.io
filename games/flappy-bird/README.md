# Flappy Bird

A small, mobile-friendly browser game built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — page markup and canvas
- `style.css` — responsive full-screen layout and sound button
- `game.js` — canvas rendering, controls, scoring, pipes, collision detection, and optional sound

## Controls

- Tap or click the game to flap.
- Press **Space** or **Arrow Up** on a keyboard.
- Use the speaker button to mute or enable sound.

## Compatibility notes

The game is designed to run inside a sandboxed iframe. Best-score storage and audio are optional and are wrapped in error handling because some sandbox configurations disable browser storage or audio APIs.
