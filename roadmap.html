Featured initiative · Planned

📱 ConfigKit Mobileconfig Studio — everything mobileconfig, in one free place

Expand the existing signed-in profile builder into a complete create, edit, validate, save, download and share workspace. The goal is to keep all core capabilities free, with no paid tiers.

Available todayStudio

Generate and download

Create profiles with the currently supported Wi-Fi, Web Clip and encrypted DNS payloads, preview the XML and download the .mobileconfig file.

Available todayPersonal library

Save profiles privately

Signed-in members can save generated profiles to their private Profile Library.

PlannedEditing

Import and edit profiles

Open an existing .mobileconfig file, inspect its payloads, edit supported settings and validate the result before exporting.

PlannedSharing

Share links and QR codes

Share profiles with clear public/private controls, revocable links and QR codes. Sharing must never expose private credentials by accident.

PlannedLibrary

Versions and organisation

Organise, duplicate and manage profile versions in a signed-in personal library.

PlannedLearning and safety

Payload reference and validation

Build a searchable payload library with explanations, examples, compatibility notes and stronger pre-export checks.

The current Studio's community post shares a title and description only, not the generated profile file. The items above distinguish existing functionality from planned work. Signing in supports saving and sharing; it is not intended to be a paid tier.
