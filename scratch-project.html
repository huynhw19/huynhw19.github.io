📦 Package your Scratch project

Prepare a portable copy of your loaded project and create a standalone HTML package with the TurboWarp Packager.

How packaging works: ConfigKit exports your current project as an .sb3 file, then opens the TurboWarp Packager. In the Packager, choose File, upload the downloaded .sb3, select HTML as the output, and download your standalone player. The Packager is an external service; the project file is not uploaded until you choose it there.

🧩 Project editor & ConfigKit Drive

Signed-in members can save private project files to their ConfigKit Drive and open them in the TurboWarp editor. The editor is provided by TurboWarp, not built into the lightweight player.

Checking your ConfigKit sign-in…

To save your edits: in TurboWarp choose File → Save to your computer, then upload the edited .sb3 below and choose “Save edited copy to Drive”. The external editor cannot directly write back into ConfigKit.

Sign in or create a ConfigKit account to unlock private cloud saving and the editor tools.

📱 Add Scratch Studio to your iPhone Home Screen

Create a small Apple Web Clip configuration profile. Installing it adds a shortcut to this Scratch Studio page; it does not install Scratch or embed your uploaded project into iOS.

Open Web Clip Builder

On iPhone: download the profile, open Settings → Profile Downloaded (or General → VPN & Device Management), review it, then install only if you trust the ConfigKit website. Alternatively, in Safari use Share → Add to Home Screen.

The profile contains only a removable Web Clip pointing to this page.
