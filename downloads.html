Install in a few steps

Platform-by-platform instructions

1Choose your platform

Download only the file intended for your device.

2Install or open

Follow the matching instructions and review security prompts.

3Sign in

Connect to the internet, open ConfigKit and sign in to your existing account.

🪟 Windows · EXE

Run ConfigKit-Windows-Setup.exe, review the Windows prompt, choose an install folder and finish setup. Launch it from Start Menu or desktop. The installer is unsigned; SmartScreen may show an unknown-publisher warning.

🍎 macOS · DMG

Open the downloaded DMG, drag ConfigKit into Applications, eject the disk image and launch from Applications. The first build is not notarized; macOS may block first launch. Only proceed if you trust the source and have checked the file.

🐧 Linux · AppImage

Run chmod +x ConfigKit-Linux-x64.AppImage, then ./ConfigKit-Linux-x64.AppImage. Some distributions may require FUSE support.

🤖 Android · APK

Download ConfigKit-Android.apk on your Android device, open it, and follow the system prompt. If asked, allow your browser or file manager to install unknown apps, return and tap Install. You can disable that permission afterwards. This APK is distributed outside Google Play.

📱 iPhone & iPad · mobileconfig

Open the ConfigKit profile builder, create and download your mobileconfig file, then open it on your Apple device. Go to Settings → Profile Downloaded (or General → VPN & Device Management), review every payload and install only if you trust the settings. A Wi-Fi password may be stored in the file.
