System requirements

Check compatibility before downloading

🪟 Windows

Windows 10 or 11 · 64-bit (x64)

Internet connection required. 32-bit Windows is not supported.

🍎 macOS

macOS 12 Monterey or later

Intel (x64) and Apple silicon (arm64) builds are provided. Internet connection required.

🐧 Linux

64-bit Linux (x86_64)

A distribution compatible with AppImage and FUSE support may be required. Internet connection required.

🤖 Android

Android 8.0 (API 26) or later

64-bit/32-bit compatibility depends on the device and APK build. Allow installation from your chosen browser or file manager.

📱 iPhone & iPad

iOS / iPadOS with Safari and profile installation support

Use a current supported OS version. The profile builder needs an internet connection and a ConfigKit sign-in.

ConfigKit desktop and Android apps are internet-connected wrappers for the hosted service; they do not work fully offline. Keep your operating system and browser up to date. Requirements may change with future releases.

Install in a few steps

Platform-by-platform instructions

1Choose your platform

Download only the file intended for your device.

2Install or open

Follow the matching instructions and review security prompts.

3Sign in

Connect to the internet, open ConfigKit and sign in to your existing account.

🪟 Windows · EXE

Run ConfigKit-Windows-Setup.exe, review the Windows prompt, choose an install folder and finish setup. Launch it from Start Menu or desktop. The installer is unsigned; SmartScreen may show an unknown-publisher warning.

🍎 macOS · DMG

Open the downloaded DMG, drag ConfigKit into Applications, eject the disk image and launch from Applications. The first build is not notarized; macOS may block first launch. Only proceed if you trust the source and have checked the file.

🐧 Linux · AppImage

Run chmod +x ConfigKit-Linux-x64.AppImage, then ./ConfigKit-Linux-x64.AppImage. Some distributions may require FUSE support.

🤖 Android · APK

Download ConfigKit-Android.apk on your Android device, open it, and follow the system prompt. If asked, allow your browser or file manager to install unknown apps, return and tap Install. You can disable that permission afterwards. This APK is distributed outside Google Play.

📱 iPhone & iPad · mobileconfig

On your iPhone or iPad, open the ConfigKit Mobileconfig Studio in Safari and sign in. Choose the payloads you want, generate the profile, review the XML, then tap Download .mobileconfig. Open the downloaded file from Safari Downloads or the Files app. Depending on your iOS/iPadOS version, you may see Profile Downloaded in Settings; open it, review every payload, and tap Install only if you trust the settings. You can also find downloaded profiles under Settings → General → VPN & Device Management. A Wi-Fi password may be stored in the file, so keep it private.
