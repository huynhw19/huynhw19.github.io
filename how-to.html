Quick start

How to use ConfigKit

Create a basic Wi-Fi configuration profile in your browser, then review it before installing.

Open the Wi-Fi builder →

Build a Wi-Fi profile

  1. Open the Wi-Fi profile builder on the home page.
  2. Enter a profile name and the exact Wi-Fi network name (SSID).
  3. Choose the network security type. For a secured network, enter its password; for an open network, choose the open-network option.
  4. Choose whether the device should automatically join the network.
  5. Select Generate & download profile. The .mobileconfig file is generated locally in your browser.

Before installing

Review first. The generated profile is not signed, and a Wi-Fi password is stored inside the downloaded file. Only install profiles you trust. Check the profile contents and confirm it is appropriate for your device; work or school devices may require an administrator to review or sign it.

The sample payloads are learning examples and may not be complete installable profiles. Supported settings can vary by operating-system version and device-management method. This independent demo is not affiliated with Apple.
