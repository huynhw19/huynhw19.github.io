Troubleshooting

Find the symptom below, check the linked tool or guide, then retry. If you report a problem, include your device, browser, exact error, and the step that failed—never include secrets.

Wi-Fi profile will not generate or download

Check that the profile name and exact network name (SSID) are entered, and that the selected security mode has the required password. Allow downloads for the site and check your browser's download list or blocked-download notice. Retry with a simple test profile if needed.

Guide: Wi-Fi quick start.

Profile preparation says the XML is invalid

Confirm the file is an XML property list, not JSON, plain text, or a binary plist renamed with a .mobileconfig extension. Include the complete plist document and remove unrelated text before or after it. Passing structural validation does not prove that payload values are supported or safe.

Tool: Prepare a profile.

Profile viewer cannot read my file

The viewer is intended for XML-format profiles. Binary plist files are not supported. Convert or export the file to XML using a trusted local tool, then inspect it. The viewer does not install, execute, or fully audit a profile.

Details: Profile viewer · Technical notes.

I downloaded a profile but cannot find or install it

On Apple devices, check Settings for the downloaded profile prompt or profile-management area. Labels and locations vary by OS version. If installation is blocked, the device may be managed or restricted; ask its administrator rather than bypassing policy. Review and trust the profile before approving it.

Read: Mobileconfig beginner guide.

DNS profile installs but browsing or DNS stops working

Verify the resolver hostname, endpoint URL, and selected protocol against the provider's official setup instructions. Check that the device can reach the resolver. If connectivity is disrupted, remove the profile through the device's normal settings and confirm the network works without it before troubleshooting further.

Tool: DNS profile builder.

Web clip shortcut does not appear or open

Check that the destination is the complete intended URL, preferably HTTPS. Confirm the profile installed successfully and inspect the Home Screen or app library. Device restrictions, site redirects, and browser behavior can affect the result.

Tool: Web clip builder.

Sign-in loops, fails, or returns to the wrong page

Use the published site URL and allow the authentication redirect to finish. Try a current browser or fresh tab and check whether privacy extensions, blocked cookies, or pop-up restrictions interfere. Record the visible error without copying access tokens, codes, or session data.

Help: Account help.

I did not receive an account confirmation email

Check spam or junk, verify the address you entered, and request another confirmation from the sign-in page if that option is available. Make sure you open the confirmation link in a browser where the sign-in flow can complete.

Help: Account guide.

Passkey, two-factor authentication, or recovery-code problem

Check the account guide for the exact factor you enrolled. Recovery codes are single-use backups for an enrolled authenticator factor; keep them in a secure place and never send them to support or post them publicly. If you still have an active session, review security settings before signing out.

Help: Account security guide.

Groups cannot be created or joined

Group features require a configured Supabase project, signed-in session, and the group schema and RPC functions. Older installations may need the November 2026 repair migration. Check the browser console for the exact RPC or permission error; never place a service-role key in browser code.

Setup: Groups setup · Repair guide · Repair SQL.

Discussion, comments, or shared-profile upload is unavailable

These features need the relevant Supabase tables, row-level security policies, and—for uploads—the mobileconfig-shares Storage bucket and policies. Check the setup guide and exact network or browser error. Do not weaken access policies or expose secret keys as a workaround.

Setup: Discussion and sharing setup.

Community profiles or follow controls do not load

Confirm that you are signed in and that the community backend setup is complete. Refresh the page and check the browser console/network panel for the failing request. Backend access policies should be reviewed rather than bypassed.

Open: Community.

A page is blank, stale, or behaves differently across browsers

Refresh the page, try a current browser or private window, and temporarily check whether extensions block scripts or downloads. Confirm JavaScript is enabled for features that need it. If one page fails, open its standalone link directly from this wiki.

I accidentally shared a password or sensitive profile

Assume the secret may have been copied. Change the affected password or credential, revoke or rotate exposed keys and tokens where possible, remove the shared item if the page provides that control, and notify the relevant account or device administrator. Do not repost the secret while asking for help.
