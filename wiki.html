Troubleshooting

Start with the symptom, check the relevant page, then retry with a small test profile. If the issue persists, note the browser, device, exact error text, and which step failed—without sharing passwords or profile secrets.

Wi-Fi profile will not generate or download

Confirm the profile name and network name are filled in, and enter a password when the selected security mode requires one. Try again in a current browser, allow downloads for the site, and check the browser's download list or blocked-download indicator. If the form reports an error, correct the highlighted field and retry.

Guide: Wi-Fi quick start.

Profile preparation says the XML is invalid

Make sure the file is an XML-format .mobileconfig/property list, not a renamed JSON, text, or binary plist file. Re-copy the complete XML document, including its opening and closing plist structure, and remove any extra text before or after it. The preparation tool validates structure; it does not certify that every payload is supported or safe.

Tool: Prepare a profile.

Profile viewer cannot read my file

The viewer is intended for XML-format mobileconfig files. It does not support binary plist profiles and is not a full security scanner. Use an XML export or a compatible plist conversion tool, then inspect the result before installation.

Details: Profile viewer notes.

I downloaded a profile but cannot find or install it

On Apple devices, check the device's Settings app for the downloaded profile prompt or profile-management area. The exact location and wording vary by OS version and device policy. If installation is blocked, the device may be managed or restricted. Do not bypass an organization policy; ask the device administrator. Only install a profile after reviewing and trusting its source.

Read: Installation and safety guide.

DNS profile installs but browsing or DNS stops working

Check that the resolver hostname and endpoint are correct, that the selected protocol matches the provider, and that the device can reach the resolver. Test by removing the profile through the device's normal settings if connectivity is disrupted, then verify the network works without it. Confirm provider-specific configuration against its official documentation before re-creating the profile.

Tool: DNS profile builder.

Web clip shortcut does not appear or open

Check that the website address is complete and uses the intended HTTPS URL. Confirm the profile was installed successfully and inspect the device's Home Screen or app library. Some device restrictions, browser behavior, or site redirects can affect the result.

Tool: Web clip builder.

Sign-in loops, fails, or returns to the wrong page

Check that you are using the published site URL, allow the authentication redirect to finish, and try a fresh tab or current browser. Temporarily check whether strict privacy settings or blocked cookies/pop-ups interfere with the sign-in flow. If the problem continues, record the redirect URL and visible error without copying access tokens or codes.

Help: Account help.

Passkey, two-factor authentication, or recovery-code problem

Use the account recovery instructions and any recovery codes saved when two-factor authentication was enabled. Recovery codes are sensitive: never send them to support, post them in discussions, or paste them into the wiki. If you still have an active signed-in session, review account security settings before signing out.

Help: Account security documentation.

Groups cannot be created or joined

Group features require the configured Supabase project, authenticated session, and database schema/functions described in the repository setup guide. If an older deployment was configured before the November 2026 repair, follow the documented group repair instructions. Check the browser console for the exact RPC or permission error; never expose a service-role key in browser code.

Setup: Groups setup guide · Group repair notes.

Discussion, comments, or shared-profile upload is unavailable

These community features require a signed-in session and the appropriate Supabase tables, row-level security policies, and—when uploading files—the mobileconfig-shares Storage bucket and policies. Check the setup guide and the exact browser/network error. Upload only eligible non-sensitive profiles; do not relax access policies or expose secret keys to fix a client-side error.

Setup: Builder discussion and sharing setup.

A page is blank, stale, or behaves differently across browsers

Refresh the page, try a private window or another current browser, and temporarily disable extensions that block scripts or downloads. Check that JavaScript is enabled where the feature requires it. If only one page fails, use the links above to open its standalone page directly.

I accidentally shared a password or sensitive profile

Assume the exposed secret may have been copied. Change the affected Wi-Fi password or credential, revoke/rotate exposed keys or tokens where possible, remove the shared item if the page offers that control, and notify the relevant account or device administrator. Do not repost the secret while asking for help.
