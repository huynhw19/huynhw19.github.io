Safety, discussion & contact

A few important reminders before using or installing a configuration profile.

Only install profiles you trust. Profiles can change device settings, configure network traffic, add certificates, or apply management controls. Read the profile and verify who supplied it. ConfigKit creates unsigned example profiles and does not install them for you.

Profile safety checklist

  • Review the profile’s organization, payload names, URLs, DNS endpoints, certificates, and settings before approving installation.
  • Use a DNS resolver and web destination whose operator you trust. DNS operators may receive information about domains your device looks up.
  • Protect generated files. Wi-Fi profiles may contain your network password; do not share them publicly.
  • Cancel installation if anything is unexpected. Check current Apple documentation or ask your device administrator if unsure.
  • The site’s preview and XML checks are basic helpers, not a security audit or a guarantee of compatibility.

Discuss safety and usage

Ask general questions, share feedback, or discuss safe profile practices in the repository’s GitHub Discussions.

Open Discussions

If Discussions is unavailable, the repository owner may need to enable it. Do not post passwords, private configuration files, device identifiers, or other sensitive information.

Contact or report a problem

Use the project’s GitHub issue tracker for questions, accessibility feedback, or to report incorrect safety guidance.

Open a GitHub issue

Issues are public. Remove personal data and secrets before submitting. For private concerns, contact the repository owner through their GitHub profile.
