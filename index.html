Configuration, made simple

Build and review mobileconfig profiles.

Create a basic Wi-Fi profile right here, or open a dedicated builder for DNS and Home Screen web clips. Profile generation happens in your browser; files are not uploaded.

Safety first: Profiles can change device settings or route traffic. Review the XML and trust the source before installation. ConfigKit does not install profiles automatically and is not affiliated with Apple. Read safety guidance and get in touch.
